# 十层分解架构 · 完整定义（零重写映射）

> 作者：晨星 | 更新：2026-10-14
> 原则：禁止从零造轮子。每层先检索世界已有最优解——顶级数学、顶级算法、顶级代码——直接复用、组合、超越。

---

## L1 算力与硬件调度层

**职责**：把计算问题映射到硬件（GPU/TPU/CPU/NPU），管理显存、通信、并行。

| 组件 | 世界最优解 | 许可证 | 复用方式 | 超越点 |
|---|---|---|---|---|
| GPU 编程 | CUDA / NVIDIA Triton (compiler) | 专有 / MIT | 直接复用 Triton 写融合核 | 针对自家负载的核融合策略 |
| 集合通信 | NCCL | BSD | 拓扑感知 AllReduce | 混合云下的分层通信 |
| 显存管理 | vLLM **PagedAttention** | Apache-2.0 | 复用分页 KV Cache 思想 | 跨请求前缀共享 |
| 并行策略 | Megatron-LM 张量/流水线并行 | Apache-2.0 | 3D 并行组合 | 自动并行搜索 |

**关键数学**：Amdahl 定律（并行上限）、Roofline 模型（算力/带宽瓶颈判定）、通信复杂度 `Ω(N/P)`。

## L2 数值与张量核心层

**职责**：张量代数、自动微分、数值稳定。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 张量框架 | PyTorch / JAX(+XLA 即时编译) | 直接复用；JAX 用于函数式可微 |
| CPU 极致推理 | llama.cpp / GGML | 量化 + mmap，端侧零依赖 |
| 数值稳定 | logsumexp、Kahan 求和、Cholesky 解 | 全套采纳为编码规范 |
| 自动微分 | 逆模式 AD（链式法则），梯度检验 `maxRelErr≈1e-7` | 手写实现校验框架 |

**验证不变量**：梯度检验中心差分 vs 解析 ≈1e-7；正交阵 `QᵀQ=I`（误差 ~2.2e-16）；Jacobi 残差 `‖Av−λv‖≈ε`。

## L3 模型与算法层

**职责**：模型结构、注意力、采样、量化。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 模型生态 | Hugging Face transformers | 直接复用 50 万+ 预训练模型 |
| 注意力 | **FlashAttention** v2/v3 | IO 感知精确注意力，直接换入 |
| 稀疏化 | MoE（Mixtral 范式）、DeepSeek MLA | 复用路由+共享专家结构 |
| 位置编码 | RoPE / YaRN 外推 | 直接复用 |
| 量化 | AWQ / GPTQ / GGUF k-quants | 精度-速度帕累托前沿选型 |

**验证不变量**：注意力输出与朴素实现数值一致（误差<1e-5）；量化模型困惑度增幅可控；温度采样分布守恒。

## L4 推理服务层

**职责**：调度、批处理、吞吐/时延优化。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 高吞吐引擎 | **vLLM**（PagedAttention+continuous batching） | 首选自托管引擎 |
| 结构化生成 | SGLang（RadixAttention） | 前缀缓存+JSON 约束解码 |
| 端侧 | Ollama / llama.cpp server | 单机一键部署 |
| 推测解码 | EAGLE / Medusa | 草稿-验证范式提速 2-3× |

**验证不变量**：吞吐 token/s 基准对比可复现；TTFT/TPOT P99 达标；约束解码输出 100% 合法 JSON。

## L5 训练与微调层

**职责**：预训练/继续训练/对齐全流程。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 分布式训练 | DeepSpeed ZeRO-3 / PyTorch FSDP2 | 按规模选型 |
| 参数高效微调 | **LoRA/QLoRA**（PEFT）、Unsloth | 单卡微调 7B 起步 |
| 对齐 | DPO（免奖励模型）/ GRPO | 复用 TRL 库 |
| 训练框架 | Axolotl / LLaMA-Factory | 配置化流水线 |

**验证不变量**：损失单调下降（异常 spike 报警）；梯度范数监控；LoRA 合并前后输出一致性校验。

## L6 智能体编排层

**职责**：规划、工具调用、多智能体协作、状态机。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 状态图编排 | **LangGraph**（持久化/检查点/人在环） | 编排骨架首选 |
| 多智能体 | AutoGen / CrewAI | 角色协作模式 |
| 提示工程 | DSPy（编译式优化 prompt） | 用指标替代手调 |
| 工具协议 | **MCP**（Model Context Protocol） | 统一工具接入标准 |

**验证不变量**：Agent 状态机可回放（检查点恢复后行为一致）；工具调用 schema 100% 校验；失败重试幂等。

## L7 检索与记忆层

**职责**：向量/词法/图谱混合检索，长期记忆。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 向量索引 | FAISS（IVF/HNSW）、Qdrant | 亿级向量毫秒检索 |
| 词法检索 | BM25（Okapi）/ Elasticsearch | 混合召回第一路 |
| 图检索 | GraphRAG / Neo4j | 多跳推理 |
| 重排 | bge-reranker / Cohere Rerank | 精排兜底 |

**验证不变量**：Recall@k 基准（BeIR）达标；混合检索召回率 ≥ 单路最优；HNSW 近似查询 vs 暴力扫描 top-k 重合度可量化。

## L8 数据与质量层

**职责**：采集、清洗、去重、版本、质量门禁。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 数据集管理 | HF Datasets / DVC | 版本化+流式加载 |
| 去重 | MinHash LSH（近似 Jaccard） | 近重复剔除 |
| 质量校验 | Great Expectations | 声明式门禁 |
| 评估 | lm-evaluation-harness | 标准基准全量复跑 |

**验证不变量**：清洗前后样本数守恒（有账可查）；去重后训练集零近重复对（阈值可调）；每份训练数据可溯源到原始快照。

## L9 可观测与安全层

**职责**：追踪、评测、护栏、红队。

| 组件 | 世界最优解 | 复用方式 |
|---|---|---|
| 追踪 | OpenTelemetry（LLM 语义约定） | 全链路 trace |
| 评测平台 | LangSmith / Langfuse（开源自托管） | prompt/trace/评分一体化 |
| 安全护栏 | Llama Guard 3 / guardrails-ai | 输入输出双向过滤 |
| 越权防护 | prompt-injection 检测（根据 OWASP LLM Top 10） | 红队用例集 |

**验证不变量**：每次调用 100% 有 trace；护栏误杀率/漏杀率有基线；敏感输出拦截率 ≥ 目标阈值。

## L10 微指令运行时层（本项目原创贡献）

**职责**：把上述九层的每个工程动作，分解为 **1024 项微指令级操作**——每条可独立执行、独立验证。

- 规范：`layer10/`（16 类别 × 64 条，ID 格式 `L10-C{cc}-{nn}`）
- 数据源：`data/layer10.json`（单一事实源）
- 生成：`scripts/build.py` → markdown + HTML
- 自检：`scripts/selftest.py` → 总数/唯一性/不变量完整性校验

**验证不变量**：总数=1024；ID 全局唯一；每条含输入/动作/输出/不变量四元组；三端（JSON/MD/HTML）内容一致。

## 零重写选型总原则

1. **先检索，后动手**：任何需求先查该领域当前 SOTA 开源实现。
2. **许可证合规**：优先 Apache-2.0 / MIT / BSD。
3. **组合优于自写**：胶水层薄到只剩配置。
4. **超越点明确**：复用之上必须写清「我们比原方案多做的那一步」。
5. **基准说话**：所有选型附可复现基准数字。
